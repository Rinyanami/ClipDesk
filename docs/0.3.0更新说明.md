# ClipDesk 0.3.0 更新说明

日期：2026-11-11。仍为个人使用的 Windows 桌面预览版。

## 四个直接入口

首页直接显示“剪贴、置顶、待办、备忘”。后三项打开独立窗口，可同时摆在桌面上；再次点击激活已有窗口。置顶窗口只是同一批剪贴的独立视图，不复制记录；取消置顶不会删除内容。待办和备忘支持缩至 300×250，置顶最小 300×320，保留可用的内容区。

每个面板右上“窗口选项”分别设置：

- 保持显示：切换其他软件时仍显示。关掉后可在失去焦点时收起。
- 始终最前：显示在普通应用窗口上方，与保持显示独立。
- 未激活时不透明度：45%–100%；悬停和操作时恢复清晰，保留标题区、最小化/最大化/关闭按钮和边缘缩放。

这些选项和大小、位置只保存在当前电脑。剪贴默认失焦收起，其他三个面板默认保持显示；它们默认不遮住普通软件。唤出剪贴时会提升到本应用的其他面板前面。

## 快捷键

“设置 → 本机使用”可分别设置四个窗口的快捷键。剪贴仍默认 Ctrl+Shift+V，新增三个快捷键默认留空，避免占用现有软件组合。可以填写 Ctrl+Alt+P、Ctrl+Alt+T、Ctrl+Alt+M 等未被占用的组合。重复、无效或被占用会明确提示；更改成组注册，失败时保留能恢复的原绑定。启动时单个冲突不阻止其他窗口入口。

## 双击输入

单击仍是复制并保持打开，不把条目移动到顶部。双击或列表 Enter 会：写入剪贴板、收起浮窗、恢复此前验证的窗口和输入框，再尝试一次粘贴，不发送 Enter。

修复收起浮窗时 Windows 短暂切换焦点导致过早放弃的问题；常驻置顶窗口被鼠标重新激活时也会重新捕获当前输入目标。剪贴和置顶之间切换保留同一输入目标。本应用待办/备忘的编辑框保留原光标和选区；普通列表不能作为粘贴目标。

目标失效、用户已切换输入位置、权限不同或系统拒绝焦点恢复时，只保留复制结果并提示手动粘贴。本轮完成源码修复及输入框证据检查，真实聊天、浏览器和原光标双击操作尚未验收，不将其写为实测通过。

## 数据与验证

沿用原数据库和同步协议，不重建用户数据。新增置顶筛选发生在查询条数限制之前；手动内容、附件、软删除、草稿和 outbox 规则保留。旧窗口配置可继续读取。

本轮实际验证、安装状态及未完成项目见《验收记录》《本机安装记录》。七牛真实接口、两台真实电脑同步、真实多屏及不同权限程序仍未完成验收。角色审查和合成检查不等于真实用户测试。
